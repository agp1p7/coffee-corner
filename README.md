# coffee-corner

一隅・咖啡角：黑白芫荽介面的沖煮配方、分段注水、斷水紀錄與風味日記網頁 App。

## 版本日誌

完整版本沿革、後續修正與撤回紀錄請見 [CHANGELOG.md](./CHANGELOG.md)。

最後一次明確更新的介面版號為 2.8.0；其後的分享卡、導覽列與 PWA 更新以提交紀錄另列，沒有補造新的正式版號。此儲存庫目前尚無 Git Tag 或 GitHub Release。

## 主要功能

- 我的咖啡：集中管理咖啡豆、器材與沖煮紀錄。
- 配方工作室：編輯參數、分段步驟與預設選項。
- 引導沖煮：選配方後依準備、沖煮、品飲三階段操作。
- 紀錄補改、兩杯比較，以及包含豆子資料與風味描述的分享卡。
- 主導覽下滑收起、上滑顯示；提供繁體中文／英文介面。
- 第一版 PWA 安裝支援，預設從引導沖煮啟動；實際安裝方式依瀏覽器支援而定。

## 資料與使用提醒

- 紀錄保存在使用裝置的瀏覽器中，沒有跨裝置自動同步；請定期匯出 JSON 備份。
- 匯入 JSON 會取代該環境的現有資料，操作前先備份。
- 目前未提供離線快取；安裝成 App 不代表已具備離線啟動能力。
- 使用者已回報平板可以使用；完整的 Android、iOS 與 PC 相容性仍需逐項驗收。
